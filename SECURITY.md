# Security policy

This app handles passwords. Please **do not** open a public issue for security problems: use GitHub's
[private vulnerability reporting](https://github.com/EmaLau/nextcloud-authentik-dav/security/advisories/new) instead.
Reports in English or Italian are both fine.

Useful details: the app, Nextcloud and Authentik versions, the settings involved (without secrets), and the steps
to reproduce. The [end-to-end environment](docs/documentation.md#development) is a good place to show the problem
without touching a real server.

Only the latest release is supported. How the app protects passwords (what is sent where, cache, brute force,
logs) is described in *Security* in the [documentation](docs/documentation.md#security).
